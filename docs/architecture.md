# Архитектура первого этапа

- Интерфейс и навигация находятся в `src/ui`. Основные расчёты вызываются через типизированный контракт `BudgetEngine`.
- `src/domain` содержит модели, чистую реализацию финансовых расчётов на TypeScript, формат денег и календарные функции. У операций календарная дата без времени. «Сегодня» и закрытие недельного периода вычисляются в часовом поясе бюджета. Периоды полуоткрытые, дата окончания исключается.
- `src/data` содержит репозиторий Dexie, версионированный формат обмена и генератор демо. Данные нормализованы, весь импорт проходит проверку до изменения базы, записи заменяются транзакционно.
- Схема Dexie v2 мигрирует только категории. Старые иконки преобразуются в эмодзи с сохранением идентификаторов. JSON-копии v1 принимаются при импорте, экспорт использует v2 и сохраняет Unicode-последовательность в поле `emoji`.
- Vite собирает статическое приложение. Workbox хранит программные ресурсы, пользовательские данные остаются в IndexedDB. При обновлении сборки интерфейс предлагает перезапуск.
- Токены интерфейса описаны в `src/styles.css`. Основные паттерны — обзор бюджета, навигация по периодам, списки и диалоги. На телефоне навигация снизу, на широких экранах слева.
- На следующем этапе реализацию `BudgetEngine` можно заменить адаптером WASM, а слой данных расширить синхронизацией. Копейки передаются целыми числами, календарные даты — как ISO YYYY-MM-DD.

## Проверка

Тесты ядра охватывают смену календарного дня и года, семь вариантов начала недели, границы месяца, копейки, доход и перерасход. Проверки в браузере охватывают основные формы и состояние после перезагрузки, мобильные размеры и офлайн.
