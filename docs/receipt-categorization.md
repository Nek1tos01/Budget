# Категоризация позиций

Budget предлагает только действующие категории текущего бюджета и показывает их эмодзи. Сопоставления проверяются в следующем порядке.

1. Точное совпадение с подтверждённым товаром.
2. Совпадение после нормализации регистра, пробелов, метки маркировки и десятичного разделителя.
3. Подтверждённое пользователем правило по фразе.
4. Соответствие товарного типа одной из существующих категорий.
5. Похожее подтверждённое название того же типа или подходящая общая категория продуктов.

При неоднозначности категория остаётся пустой. Словарь описывает товарные типы и никогда не создаёт категории. Явно сохранённое правило работает и с произвольным названием категории. Удалённые и архивные категории исключаются из предложений.

При исправлении можно запомнить соответствие для всего названия или общей фразы. Правила можно просматривать, менять и удалять. В общем бюджете они синхронизируются через ту же версионную очередь, что и остальные настройки бюджета. Одновременное редактирование одного правила разрешается через экран конфликта.
