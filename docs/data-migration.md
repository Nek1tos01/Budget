# Перенос и резервные копии

## Из локального бюджета в общий

1. В настройках откройте «Общий бюджет» и выберите «Перенести текущий бюджет в общий».
2. Проверьте количество категорий и операций. Сохраните предложенную JSON-копию.
3. Введите имя профиля, подтвердите отправку и создайте бюджет.
4. Сохраните показанный код восстановления. После подтверждения переноса и получения свежих данных приложение откроет общий бюджет.

Создание сессии и отправка данных являются отдельными операциями. Незавершённый перенос сохраняется на устройстве с прежним ID запроса. При повторе сервер возвращает то же подтверждение. Если общий бюджет изменился, сервер не перезаписывает его при старом курсоре. Просмотрите актуальные данные и подтвердите новый перенос. Локальная IndexedDB остаётся доступна после выхода из облачного бюджета.

## Совместимость

- Копии v1 с прежними иконками и копии v2 с Unicode-эмодзи могут быть прочитаны и преобразованы.
- Формат v3 сохраняет исторических участников, фактических плательщиков и авторов операций. Копейки в пользовательском JSON — безопасные целые, а в API — десятичные строки.
- ID категорий и операций сохраняются. Локальные участники сопоставляются с участниками общего бюджета, и ссылки в операциях переписываются вместе с ними. Автор неизвестной импортированной записи определяется импортирующим владельцем.
- Копия включает финансовые данные. Cookies, приглашения и коды восстановления в неё не входят.
- Импорт в общий бюджет выполняется владельцем после явного подтверждения и проверяет текущий курсор. Некорректная копия не изменяет данные.
