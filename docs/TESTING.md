# Проверки Budget

## Подготовка и базовый прогон

Из корня Budget с Node.js 24 выполните `npm ci`. Для браузерных тестов установите движки командой `npx playwright install chromium webkit`.

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

Vitest проверяет финансовые расчёты через существующий WASM, модель и хранение чеков, разбор OCR, перенос лимитов, миграцию категорий и облачный клиент. Сборка проверяет TypeScript и собирает приложение с Vite.

## C++ и WASM

```sh
cmake -S cpp/budget-core -B build/budget-native
cmake --build build/budget-native --config Release
ctest --test-dir build/budget-native -C Release --output-on-failure
npm run build:wasm
npm test
npm run build
npx playwright test tests/e2e/budget-wasm.spec.ts
```

Для пересборки WASM нужно активировать Emscripten SDK. Требования и установка описаны в [документации ядра](CPP_WASM.md). Браузерный тест проверяет доставку WASM по HTTP, повторную загрузку после ошибки, прогноз и работу после офлайн-перезагрузки.

## Браузер и облако

| Команда | Что запускает |
| --- | --- |
| `npm run test:e2e` | Chromium и WebKit с Vite Preview на порту 4187. Требуется свежий `dist/` после `npm run build`. |
| `npm run test:e2e:receipt-media` | Chromium и WebKit с Vite Dev на порту 4189. Проверяет OCR в локальном worker, QR из изображения и видеопотока, отмену и освобождение камеры. |
| `npm run test:cloud` | Интеграционные проверки API на локальном Wrangler и временной базе D1. |
| `npm run test:e2e:cloud` | Два устройства, офлайн-очередь, перенос и восстановление в Chromium и WebKit. Требуется свежий `dist/`. Тестовый сервер применяет миграции к временной D1 и по умолчанию слушает порт 4191. |

## Ручная проверка чеков на iPhone

1. Откройте тестовую сборку по HTTPS в Safari. Повторите сценарий после добавления Budget на экран «Домой».
2. Считайте QR задней камерой, сверьте дату и итог. После сохранения отсканируйте его повторно и откройте существующий чек. Проверьте возврат покупки с QR и отказ в разрешении камеры.
3. Сделайте фото или выберите его в галерее. Проверьте поворот, обрезку, коррекцию и отмену OCR. Сверьте весовые товары, скидку и итог с оригиналом.
4. Исправьте строку, назначьте категорию нескольким позициям и сохраните чек. Откройте его в истории, измените категорию и проверьте недельный и месячный бюджеты.
5. В общем бюджете запустите OCR онлайн для загрузки моделей. Добавьте чек без сети, перезапустите приложение, восстановите сеть и сверьте позиции и копейки на втором устройстве.

Playwright WebKit покрывает интерфейс и сценарии браузера. Разрешения реальной камеры, фотогалерею и поведение при ограниченной памяти проверяйте на физическом устройстве.
