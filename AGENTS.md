# Budget

## Карта проекта

- `src/ui/` — React-экраны бюджета, аналитики, истории, категорий, настроек и импорта чеков. Общие компоненты в `shared.tsx`, токены тем и адаптивность в `src/styles.css`.
- `cpp/budget-core/` — финансовые расчёты в целых копейках и календарь периодов. `src/domain/engine.ts` и `budget-wasm.ts` связывают приложение с ядром. При изменении ABI обновляйте адаптер и пересобирайте `budget-core.wasm`.
- `src/domain/receipts.ts` — валидация и проекция чеков в операции. `src/receipts/` — локальные QR и OCR.
- `src/data/repository.ts` — Dexie, проверка резервных копий и выбор локального или общего бюджета. `src/cloud/` — протокол, офлайн-очередь и версионная синхронизация.
- `functions/api/v1/`, `server/`, `migrations/` — Cloudflare Pages Functions, проверки сессий и D1. Миграции применяются последовательно.

## Проверки

- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
- После изменений C++ — `cmake -S cpp/budget-core -B build/budget-native`, `cmake --build build/budget-native --config Release`, `ctest --test-dir build/budget-native -C Release --output-on-failure`, `npm run build:wasm`. Подготовка SDK описана в `docs/cpp-wasm.md`.
- При изменении D1 или синхронизации — `npm run test:cloud`. Браузерные проверки при необходимости — `npm run test:e2e`, `npm run test:e2e:cloud`, `npm run test:e2e:receipt-media`.

## Сохранность данных

- Сохраняйте совместимость старых записей и JSON. Отсутствующий режим действует как `weekly_and_monthly`. Для D1 добавляйте новую миграцию, сохраняющую данные, версии и ревизии.
- Храните деньги в целых копейках. Сохраняйте фискальные реквизиты и фактические суммы. Операции из чека вычисляются из документа и не сохраняются второй раз.
- Изменения связанных сущностей должны сохраняться атомарно. Для синхронизации сохраняйте изоляцию бюджетов, проверку версий и идемпотентность.
- Используйте изолированные тестовые базы. Сброс пользовательской базы, production-миграции и деплой требуют явного разрешения.
